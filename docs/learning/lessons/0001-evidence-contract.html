先学一个区别

结构化输出让程序得到形状明确的数据，例如字符串、整数列表和布尔值。数据是否属于当前用户、引用是否存在、内容是否支持结论，需要另外判断。

本课选择一个最低契约：记忆回答没有有效引用时，不能作为有依据的答案交付。主资料：Pydantic AI Output。

合法 JSON → 合法引用 → 结论得到证据支持。这三层需要分别检查。

先预测，再展开答案

本轮只检索到记忆 12：“面试在周四”。模型返回：

当前程序过滤掉 999，但没有重新判断是否应该弃答。你预测最终三个字段是什么？为什么旧测试可能通过？

把五种情况写进验收

情况应发生什么
没有检索命中直接弃答，不调用回答模型
全部引用非法弃答，并替换原无依据结论
引用为空但未弃答同样不能作为正常回答
合法与非法引用混合去掉非法项；本课正常案例的答案仅依赖合法项
模型主动弃答保持弃答，清空误附的引用

引用存在仍可能指错证据。本课完成后，也不能宣称“解决了幻觉”。

三个追问，自答后核对

为什么不只改提示词？提示词能影响模型，但边界行为需要程序和测试保证。

为什么用假模型？这次检查的是程序怎样处理指定输出，不是评估模型能力；固定输出便于稳定复现。

合法引用就能保证正确吗？不能。模型可能引用正确的记忆 ID，却给出相反的结论，需要后续证据支持评价。
