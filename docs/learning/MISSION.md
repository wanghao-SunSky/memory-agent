# Mission: 用 memory-agent 准备 Agent 应用开发面试

## Why
通过一个能解释、修改和验证的真实项目，形成 Agent 应用开发的面试证据。重点是从三年 Java 后端经验迁移到模型调用、记忆、工具执行与可靠性。

## Success looks like
- 能独立讲清一个请求从进入 API 到模型决策、存储、检索和交付的过程。
- 能为实际失败写验收条件、补测试、完成小改动，并解释效果和限制。
- 能用同一批任务比较方案，拿出错误案例、过程记录和可复算结果。

## Constraints
- 每周约 8 小时，整体参考 6–8 周；预算不是学习完成承诺。
- 中文讲解，保留必要的英文术语。已有 Python 项目继续使用，关联 Java 工作经验。
- 每课一个主要问题，先判断，再实操，再反馈；不把材料交付视为已掌握。

## Out of scope
- 交易、Web3、跨机器 Coding Agent 转接。
- 为凑技术栈整体重写、同时学习多套框架，或提前加入大规模多 Agent、图数据库和模型训练。
