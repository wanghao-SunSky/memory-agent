本课决策

无命中：直接弃答。模型已弃答：保留弃答并清空引用。模型未弃答但无有效引用：替换无依据结论并弃答。存在有效引用：通过本层检查，语义正确性仍需另验。

验证方法

用 FunctionModel 固定边界输出，区分程序测试和真实模型评测。先看原始断言失败，再做最小修改和相关回归。不能把依赖安装失败当作业务缺陷复现。
